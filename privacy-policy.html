🔐 Política de Privacidade

Última atualização: 21 de setembro de 2026
Aplicável a: conexaocrm.com e somamentoria.com

1. Introdução

A Conexão CRM ("nós", "nosso" ou "nos") opera as plataformas conexaocrm.com e somamentoria.com. Esta página informa as políticas de privacidade referentes à coleta, uso e divulgação de dados pessoais quando você usa nossas plataformas.

2. Dados que Coletamos

Coletamos vários tipos de informações nas seguintes situações:

  • Dados de Autenticação: Nome, e-mail, foto de perfil (fornecidos via Google OAuth)
  • Dados de Perfil: Localização, senioridade, ferramentas, experiência profissional
  • Dados de Interação: Filtros utilizados, vagas visualizadas, avaliações enviadas
  • Dados Técnicos: Endereço IP, tipo de navegador, sistema operacional, timestamp de acesso
  • Dados Opcionais: LinkedIn, WhatsApp e outras informações que você voluntariamente compartilha

3. Base Legal para Processamento

Processamos seus dados com base em:

  • Seu consentimento explícito (autenticação via Google)
  • Necessidade contratual (fornecimento do serviço)
  • Obrigações legais (LGPD, GDPR)
  • Interesses legítimos (melhoria do serviço, segurança)

4. Como Usamos Seus Dados

Utilizamos suas informações para:

  • ✅ Autenticação e acesso à plataforma
  • ✅ Personalização de conteúdo e recomendações
  • ✅ Análise de uso (Google Analytics com dados anonimizados)
  • ✅ Melhoria contínua do produto
  • ✅ Comunicações sobre atualizações importantes
  • ✅ Conformidade com obrigações legais
  • ❌ NÃO vendemos seus dados para terceiros

5. Segurança de Dados

Implementamos medidas de segurança robustas:

  • 🔒 Criptografia HTTPS/TLS em trânsito
  • 🔒 Armazenamento seguro via Supabase (PostgreSQL criptografado)
  • 🔒 Autenticação multi-camadas com OAuth 2.0 do Google
  • 🔒 Row Level Security (RLS) no banco de dados
  • 🔒 Sem armazenamento de senhas (OAuth)

6. Compartilhamento de Dados

Seus dados são compartilhados apenas com:

  • Google (para autenticação OAuth)
  • Supabase (infraestrutura de banco de dados)
  • Google Analytics (estatísticas anonimizadas)

Nunca compartilhamos seus dados pessoais com terceiros sem seu consentimento explícito.

7. Retenção de Dados

Armazenamos seus dados enquanto sua conta estiver ativa. Você pode solicitar a exclusão completa a qualquer momento. Os dados técnicos (logs) são retidos por até 90 dias para segurança.

8. Seus Direitos (LGPD/GDPR)

Você tem o direito de:

  • 📋 Acessar: Receber cópia de todos os seus dados
  • ✏️ Corrigir: Atualizar informações incorretas
  • 🗑️ Deletar: Solicitar exclusão permanente
  • 📤 Portabilidade: Receber dados em formato padrão
  • 🚫 Revogar: Retirar consentimento
  • ⚖️ Reclamar: Junto à autoridade de proteção de dados

9. Cookies e Rastreamento

Utilizamos cookies apenas para:

  • Autenticação (token de sessão)
  • Preferências do usuário (tema, idioma)
  • Google Analytics (análise agregada)

Você pode desabilitar cookies nas configurações do navegador, mas isso pode limitar funcionalidades.

10. Mudanças nesta Política

Podemos atualizar esta política ocasionalmente. Notificaremos mudanças significativas via e-mail. Seu uso contínuo da plataforma após mudanças constitui aceitação.

⚠️ Importante: Esta plataforma usa autenticação do Google. Ao fazer login, você também aceita a Política de Privacidade do Google.

  • 🌐 Site: conexaocrm.com
  • ⚖️ Se não ficar satisfeito, você tem direito de reclamar junto à ANPD (Brasil) ou autoridade de proteção de dados local
